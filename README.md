# README - ONG Solidariedade

Este repositório contém o código-fonte da aplicação web desenvolvida para a ONG Solidariedade, focada em apresentar a missão institucional, projetos e canais de contato da organização.

## Sobre o Projeto

O projeto foi estruturado com foco em performance, acessibilidade e boas práticas de desenvolvimento web moderno. A aplicação utiliza uma abordagem modular, otimização de ativos visuais e entrega estática de alta performance.

## Tecnologias e Otimizações Utilizadas

* HTML5 e CSS3: Estrutura semântica e estilização modular otimizada.
* JavaScript Moderno: Organização por módulos para reutilização e injeção de componentes.
* Otimização de Imagens: Utilização de formatos modernos de alta compressão (AVIF e WebP) com fallback para imagens tradicionais através da tag picture.
* Minificação: Redução do tamanho dos arquivos de código para acelerar o tempo de carregamento global da página.
